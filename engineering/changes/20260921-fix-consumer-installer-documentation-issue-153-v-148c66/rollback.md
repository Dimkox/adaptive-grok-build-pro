# Recovery

Trigger on broken links, absent mandatory inputs, weakened safety wording or changed consumer bytes.

1. Stop applying the candidate payload and preserve failing evidence.
2. Forward-fix template selection/content in the isolated branch or prepare a reviewed narrow revert.
3. Rerun focused checks, full verification and independent reviews before authorized delivery.

Existing consumers never auto-update; any repair preserves their user instructions and managed README ownership.

No deployed state or production migration is changed by this source repair. Recovery of external consumers or services is separately authorized.
