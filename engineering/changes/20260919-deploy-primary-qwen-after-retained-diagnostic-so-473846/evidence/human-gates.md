# Existing user delegation

The user's “Переводи на новый но по правилам фабрики” and subsequent “Делай” authorize continuing the same existing Claw primary upgrade after the source diagnostic correction. This supplies scope_and_design_approval, migration_or_external_write_approval and production_action_approval for the finite primary-only operation described in brief.md: same service, approved qwen-omni-intl profile, latest independently attested merged source, complete backup/recovery and at most one new synthetic job.

No permission is inferred for CI policy/keys/trust stores, other production targets, public publication or unbounded provider retries. Exact grants are generated only after target/script/resource binding is concrete. These are local delegated operation grants, not human-signed security envelopes and not merge authority.
