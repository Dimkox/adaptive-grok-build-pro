# Rollback plan — External Observer truth projection v1

## Triggers

Disable/stop observation on any external-write surface, credential leak, arbitrary URL, false fresh/delivered/released projection, mixed moving snapshot, raw-body persistence, unsafe path, corrupt digest/chain, unbounded request or architecture edge into controller/Factory/Trust/production.

## Rollback and recovery

Before any separately authorized activation, rollback is a source revert/forward-fix. A future runtime rollback stops the separately activated observer, preserves the last normalized public snapshot for diagnosis, quarantines corrupt ignored state, and changes only observer source/config/schema/CLI artifacts. It never changes PROJECT_STATE claims, receipts, GitHub, Factory, Trust CI or production.

After rollback, prove the observer has no process/network/write edge, validate existing controller/Trust CI behavior unchanged, and render retained evidence explicitly stale/unavailable. Missing the `2026-09-04 23:59 UTC+3` deadline never permits stale evidence or gate bypass.
