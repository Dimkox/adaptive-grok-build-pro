# Evidence

Store human-readable review reports here. Machine receipts live under `.grok-stack/runtime/receipts/` and are bound to the current repository fingerprint.

`test-review.md` records the prior fingerprint's TR-001 failure and is superseded as review evidence after the direct-classifier test addition. It is retained unchanged; `test-review-remediation.md` records the repair verification and a fresh independent test review is still required for the new fingerprint.
