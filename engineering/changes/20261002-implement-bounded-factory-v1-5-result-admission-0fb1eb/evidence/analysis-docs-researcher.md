# Requirements mapping

This slice supports only the F25/AC63/BB-R08 negative-state and contract foundation: versioned closed envelope/API identity, authenticated seams, explicit unavailable runtime channels and offline sanitizer evidence. It does not prove durable replay, interception, dispatch, protected next-model delivery, full F25/BB-R08, U3/U6/U7 completion or M8.

U4 and Apple AC31-38 are explicitly excluded by the owner. Preserve this limitation in contracts and release claims.
