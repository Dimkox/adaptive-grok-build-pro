## 5. Audit of PR #133 (head 2cbfa12) — per-site disposition

Whitelist updated: `"anyOf"` 1079 (plus `"$defs"` 1067 and `"format"` 1078 admitted). New reason/mechanism: `unsupported_schema_comparison` added to reasons and mapped last to `CompatibilityResult("unsupported", ("unsupported_schema_comparison",))` at 3208-3209 (overrides any other reasons incl. event_meaning_changed).

- **Site 2 (canonical-equality loop) — deliberately NOT updated; anyOf unreachable there.** Head 2187 still `("oneOf","allOf","if","then")`. A node carrying anyOf on either side is consumed by the dedicated block 2128-2166 which **returns** at 2166 before 2187; the block itself byte-compares anyOf siblings (2134-2141 → unsupported_schema_comparison) and delegates branches to `_anyof_format_changed` 1950-2073 and `_union_inclusion` 1888-1948. anyOf *nested under* oneOf/allOf children still reaches the block via the child's own call (probe: `{"oneOf":[{"anyOf":[...]}]}` desc-only edit → `unsupported, ('unsupported_schema_comparison',)`), and oneOf-array byte drift is caught at 2187.
