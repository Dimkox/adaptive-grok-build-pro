# Architecture — port of the advisory workflow-artifact compiler onto current main

> Typed authority: [`change-spec.yaml`](change-spec.yaml). This Markdown explains context and cannot override typed IDs, risk, acceptance criteria, forbidden outcomes, or approval scopes.

## Current behavior

`main` verifies native M1–M9 surfaces only; third-party workflow documents (Spec Kit/BMAD/Superpowers) are prose conventions with no machine boundary. The complete adapter implementation existed only uncommitted on the stale `feature/workflow-artifact-adapters` worktree.

## Proposed behavior

A deterministic, model-neutral compiler ingests explicitly manifested framework documents as untrusted advisory data and emits stable `WorkflowTaskGraphV1` plus `WorkflowConvergenceReportV1`; `grok_verify` checks stored artifacts read-only for the active change only; `workflow_sources` in toolchain config plus `tests/test_workflow_sources.py` and ADR-0001 make upstream currency a falsifiable contract without version-gating the parser.

## Components and boundaries

- `.grok-stack/adaptive_grok/workflow_artifacts.py` — loader/adapters/DAG/convergence/CAS (no authority).
- `scripts/grok_artifacts.py` — import/compile/converge/validate/export CLI, active-change-bound, write only via `--write --expected-digest`.
- `schemas/workflow-*-v1.schema.json` — closed contracts (registered in architecture model as three contracts).
- `verification.py` — one new read-only check; `receipts.py` — hardened evidence validation shared with the compiler.
- `.specify/` — one committed advisory task projection under the no-vendoring guard.

## Data flow

manifest → descriptor-bound reads → WorkflowSourceV1 → adapter candidates → route-bound graph (+receipt/fingerprint ephemeral effective status) → convergence report → optional exact-target CAS publication; native route/governance/receipts/Trust CI never read graph output as authority.

## API and event contracts

Three JSON Schemas (contracts/), CLI exit codes (0 pass/1 blocking), canonical UTF-8 sorted-key compact JSON with trailing newline. No events, no HTTP.
