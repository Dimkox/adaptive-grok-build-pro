Apply the same matcher to `_score`'s domain use and any technical-prompt check that is intended to agree with it. Keep intent priority separate; open PR #140 addresses release intent.

- Add focused tests in `tests/test_repo_router.py` for the exact #155 text, positive frontend and Bitrix prompts, short token boundaries (`ui`, `api`, `d7`, `sql`, `1c`), short-only owner fallback, and serialized keyword evidence.
