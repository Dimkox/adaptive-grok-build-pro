# Requirements

Typed criteria AC-001 through AC-007 in `change-spec.yaml` define acceptance. Receipt references require future evidence; they are not pass claims.

- Qwen success prevents all reserve calls. Confirmed eligible failures advance through Grok, OpenAI, Claude and OpenRouter once each; all failures terminate.
- Each attempt has truthful identity, phase/finality, artifact presence and known/unknown usage. Provider authentication differs from local API authorization.
- Stable logical/child IDs, intent-before-send persistence and read-only reconciliation prevent duplicate paid calls on replay/restart.
- Private config, bounded input retention, deadlines, scoped authorization and exact source/profile validation remain enforced.
- Policy refusal, unsafe input, caller authorization and integrity failure never trigger reserve calls.
- All five key names and usable model profiles are supported. Anthropic Messages and OpenRouter pinning/accounting are explicit.
- Direct calls and historical evidence retain meaning. Common CLI is the automatic entrypoint; it does not publish.

External Trust CI remains merge authority. General coding, pilot acceptance, M8/M9 activation and accepted-tasks-per-euro do not follow from this change.
