# Bounded design

Add an optional local evidence accounting utility under existing local preflight ownership. It consumes explicitly selected JSON snapshots; authenticated GitHub collection is a separate read-only audit. No service, database, provider, dependency or external-write capability is introduced.

Raw observations and detailed reports remain outside the public checkout. Public artifacts contain generic source, synthetic tests/examples, instructions and sanitized workflow reports. Imported snapshots provide provenance claims, not external attestations.

Represent repository completeness, delivery ref, PR identity/state, merge actor type, separate task-acceptance evidence, operator-intervention coverage, exact profile fields and evidence references. Missing information stays unknown. Show PR facts, source reachability, accepted tasks and qualification completeness separately.

Preserve factory AutonomyTupleV1, M7AutonomyBridgeV1 and L2 ceiling. Do not coerce imported history into ready bundles or fabricate human decisions. No existing contract version changes. Route-selected architecture analyses refine the minimum input/report shape before implementation.
