# Private reconstruction reconciliation

The three user-identified consumer cases were inspected using pinned delivery refs, paginated pull-request records and original change/task documents. Default-branch identity was checked separately from actual delivery-ref identity. Detailed sources, identifiers, SHAs, JSON and CSV reports are retained outside this public repository.

The actual normalized input passed the new offline validator. Its report was independently reconciled against the separately collected source summaries for project count, PR states, observed work-unit count and documented validation count. Missing complete task inventory, human acceptance, operator sessions, metrics and historical profiles remain unknown. Conditional and failed validation claims remain documented validation and are not relabeled as acceptance. PR-to-task links preserve the limited contains-documented-commit relation in the private context sidecar.

The result confirms existing delivery evidence while leaving qualification unassessed. It has `m8_qualification=not_evaluated` and `authority_effect=none`. Source references are imported claims; the CLI does not authenticate them or fetch their contents. No private source identifiers or source code are needed by this public implementation.
