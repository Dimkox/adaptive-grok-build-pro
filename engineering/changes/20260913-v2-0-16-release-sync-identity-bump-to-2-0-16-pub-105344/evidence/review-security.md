- **[Low] `tests/test_project_state.py:17` misattributes the anchor.** `OBSERVED_MAIN_SHA = "1a8c8917…"` is commented `# current main tip (PR #72 merge)`; `1a8c891` is PR **#77**'s merge (`e737dd5` is #72, as `PROJECT_STATE.json:328` itself says).
