# Bounded design

Only the Trust CI test module is executable scope. Derive a unique dedicated host, inbound Funnel URL and App ID from their existing named report/spec/plan/decision fields. Admitted placeholders are exactly ci-host, redacted-tailnet-host and redacted-app-id in angle brackets. Concrete values must be syntactically bounded and mutually consistent. Funnel URL remains HTTPS, a ts.net host, and /webhooks/github, without credentials, port, query or fragment. Concrete fixtures are synthetic.

No public placeholder is translated into a live identity. These are historical/public document consistency checks, not external authority. Coordinated concrete identity changes across every document are a known documentary limitation; the deployed exact-SHA App gate remains authoritative. FIT-TRUST-CI-SEPARATION remains unchanged: no .grok-stack, architecture, factory or product scripts on this branch.
