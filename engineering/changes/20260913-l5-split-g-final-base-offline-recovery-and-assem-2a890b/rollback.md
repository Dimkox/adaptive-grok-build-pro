# Rollback and recovery

Source revert removes this operator surface without executing it. A populated deployment requires a v2-capable reader or a consistent pre-v2 snapshot. Stop runtime before preserving original roots; restore only absent original paths, keep live mode disabled, preserve partial failures for inspection and reconcile publication state by observation. Restoring SQLite/artifacts does not restore the external site pointer. Runtime installer remains an unexecuted inactive template in this change.
