## Problem

Add new browser UI functionality to Adaptive Grok Build Pro: create a one-command local HTTP demo application with a polished responsive dashboard using real repository routing, typed-spec, architecture, governance, and verification-summary logic against bundled sample data; add automated tests and user documentation. Do not perform external writes.

## Outcome

An investor can start a polished local dashboard with one Python command and demonstrate, in under five minutes, how the product turns a prompt into deterministic routing, typed intent, architecture/governance evidence, and an honest verification summary.

## Scope

### In scope

- Loopback-only dependency-free HTTP server and responsive dashboard.
- Real read-only routing, typed-spec, architecture, and governance calls.
- Bundled validated sample evidence with explicit provenance.
- Closed health, snapshot, and bounded prompt-preview API.
- Accessible loading, validation, degraded, stale/offline, and mobile states.
- Installer/package integration, tests, demo guide, and product docs.

### Out of scope

- Provider execution, code mutation, M4 queue/database/worker, or cloud hosting.
- Live GitHub/Trust CI actions, approvals, push, merge, publication, deployment, or telemetry.
- Arbitrary file browsing, shell execution, uploads, or persistent browser storage.

## Constraints

- Backward compatibility: preserve CLI/installer behavior; no root packaging marker or JS toolchain.
- Data/privacy: no secrets, environment, raw logs, absolute paths, or private reasoning in responses.
- Performance: bounded local projections; prompt <= 4,000 characters and body <= 16 KiB.
- Operational: bind only to `127.0.0.1`; work without outbound network access.
