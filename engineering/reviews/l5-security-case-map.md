# L5 defensive case map

This map answers the request to prioritize security-sensitive cases that might be mistaken for attack instructions by a model's moderation. These are local defensive tests and review findings, not confirmed Qwen moderation triggers. The original `data_inspection_failed` trigger has not been isolated. No adversarial moderation probe or safeguard bypass is claimed.

Source: final assembly `e6a813e4c16543f262ced2d9ea353caaad9452d1`, PR [#71](https://github.com/Dimkox/adaptive-grok-build-pro/pull/71). Priorities below order the defensive work; they are not vulnerability severity scores. The [delivery ledger](l5-split-delivery.md) records exact local verification, independent review and external check status separately.

## Remaining bounded observation

SEC-D-01, P3: an object/list in SSE scalar fields `finish_reason` or `delta.role` raises `TypeError` before provider-specific classification. The independent disposable application reproduction produced `needs_human` / `internal_failure`, no artifact or provider evidence, and an empty quarantine. A direct probe CLI traceback is a source-based inference, not an executed CLI result. This is a follow-up robustness issue; no publication or credential boundary bypass was demonstrated. See the [independent security review](../changes/20260913-l5-split-d-bounded-http-models-and-durable-runti-bec1fc/evidence/security-review.md).

## Interpretation limits

Passing these cases proves the recorded local behavior, not complete penetration-test coverage or provider moderation behavior. PDF parsing has subprocess/resource bounds, not kernel-enforced isolation from host files/network. Current assembly has not been installed or activated on a real hosting target. The historical synthetic `qwen-intl` / `qwen-plus` live request does not establish current-head connectivity, Omni/media acceptance or the cause of the original moderation rejection.
