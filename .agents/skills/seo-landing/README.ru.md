# SEO Landing для Codex

Repository-scoped skill для Codex: генерирует статические SEO-лендинги, проводит
аудит без изменений и точечно исправляет существующие страницы. Явный запуск —
`$seo-landing`; подходящий режим также может быть выбран по формулировке задачи.

## Режимы

- `generate`: собирает подтверждённые данные брифа, по умолчанию создаёт проект в
  `side-projects/seo-landings/<project-slug>/` и ждёт явного одобрения HTML до
  валидации.
- `audit-only`: читает заданный URL или локальную страницу, возвращает evidence и
  не создаёт и не изменяет файлы проекта.
- `fix-existing`: исправляет только названные дефекты, сохраняет несвязанный
  контент и использует тот же stop point перед валидацией.

Если домен или ключевые слова не заданы, генерация останавливается до создания
каталога проекта. Skill не придумывает факты, юридические тексты, endpoints,
права на материалы, schema-данные, canonical origin или результаты измерений.

## Примеры для Codex

```text
$seo-landing Собери статический SEO-лендинг из этого проверенного брифа
$seo-landing Аудируй https://example.test/ без изменений
$seo-landing Исправь CLS в этом локальном index.html
```

Подробные контракты performance, accessibility, server, video и map находятся
в `references/` и читаются по необходимости. Результат всегда остаётся в
отдельном проектном каталоге; skill не выполняет deployment, publication,
отправку форм, чтение секретов или production mutation без отдельного точного
разрешения.

## Проверки и доказательства

В отчёт попадают только измеренные результаты, а недоступная проверка отмечается
как blocker. Lighthouse — лабораторное измерение; автоматизированный accessibility
score не является WCAG-сертификацией, а валидный structured data не гарантирует
поисковую функцию.
