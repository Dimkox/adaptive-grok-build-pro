# Task Triage

Recover facts from the repository first. Separate:

- the user problem and observable outcome;
- current behavior and evidence;
- requested behavior;
- constraints and non-goals;
- product decisions only the user can make;
- technical facts the repository or primary documentation can answer.

Classify the work as micro, standard, or high-risk. Do not create implementation code during triage. Produce a compact brief suitable for the active change package.
