# AI and RAG Change

Version prompts, model IDs, tools, chunking, embeddings, and indexes. Define evaluation cases before optimization. Enforce tenant filters and deletion propagation. Treat retrieved content as untrusted data. Prevent retrieved text from changing system/tool policy. Measure quality, latency, cost, fallback behavior, refusal, and human escalation. Consequential external actions require human approval.
