# Security-Sensitive Change

Map assets, actors, trust boundaries, entry points, and abuse cases. Verify authorization at the server-side resource boundary, not only in UI. Validate input, output encoding, CSRF/SSRF/injection, secret handling, logs, tenant isolation, rate limits, recovery, and auditability. Require independent security review and explicit human gates for irreversible or production actions.
