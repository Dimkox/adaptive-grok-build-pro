# Винстон Вульф — посадочная v2

Неофициальная русская фан-страница о персонаже Уинстоне Вульфе из фильма «Криминальное чтиво» (1994). Не услуга, не бизнес, без заявок.

## Просмотр

```bash
python3 -m http.server 4174 --bind 127.0.0.1 --directory side-projects/seo-landings/winston-wolfe-pulp-fiction-v2
```

Откройте `http://127.0.0.1:4174/`.

Индексация выключена (`noindex, nofollow`), пока нет канонического домена.
