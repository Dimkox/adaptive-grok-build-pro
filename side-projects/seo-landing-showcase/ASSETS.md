# Asset manifest

Витрина не использует растровые изображения, SVG, внешние шрифты или сторонние
медиа. Визуальные элементы построены только средствами HTML и локального CSS,
поэтому для этой версии нет отдельных файлов, лицензий или сетевых источников.

`browser-contract.mjs` является локальным validation runner, а не runtime asset:
`index.html` его не подключает. Runner использует установленный Chrome только во
время явного тестового запуска и сохраняет evidence в переданный каталог.
